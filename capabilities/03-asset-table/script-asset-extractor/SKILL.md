# 剧本资产表提取

输入一个标准剧本 docx，输出 Excel 资产表，包含 4 个 sheet：人物、场景、道具、场次总表。每个资产可以有多个状态，表里一行对应一个状态。

脚本目录：`.claude/skills/script-asset-extractor/scripts/`（下文用 `$S` 指代）
依赖：`python-docx==1.1.2`、`openpyxl==3.1.5`

## 正式输出

1. **`assets.json`** - 所有资产数据（人物、场景、道具及其状态）
2. **`<剧名>-资产表.xlsx`** - 最终交付的 Excel 表格

其他文件（`scenes.json` 等）为临时中间文件，保留在工作目录但不作为正式输出向下传递。

## 流程

### 1. 解析剧本

在剧本所在目录建一个工作目录 `<剧名>_资产提取/`，中间文件都放在里面。

```bash
python3 $S/parse_script.py <剧本.docx> <工作目录>/scenes.json
```

检查输出的集数、场次数和警告。有「未识别行」警告的话，说明剧本格式不标准，先告诉用户哪些行有问题，再决定是否继续。

### 2. 分批提取资产

开始前先读 `references/asset_schema.md`，判定规则和 JSON 格式都在里面。

每次读 5 集：

```bash
python3 $S/show_episodes.py <工作目录>/scenes.json 1 5
```

每读完一批，就把新发现的资产、新状态、新增场次合并进 `<工作目录>/assets.json`：
- 已有资产：在对应状态的 `scenes` 里追加场次；出现换装或外观大变化时，新增一个状态
- 新资产：按编号规则追加
- 一直跟踪每个人物「当前穿的是哪一套」，后续场次没有换装描写就沿用当前状态
- 新增状态时，`evidence` 必须是这一批里刚读到的原文短句，状态名和描述必须和这句原文对得上——不要凭空想象一个"听起来合理"的状态（比如看到后面有婚礼剧情，就提前编一个"婚礼礼服"塞进去）。状态永远是先有原文依据，再有状态，不是反过来
- 给一个状态加场次号之前，确认这一场的「人物：」行里确实写了这个人物的名字（或别名）。不要凑数、不要把相邻场次的状态延续到这人其实没出场的那一场

不要一次读完全剧再提取，容易漏掉场次和状态切换。

### 3. 校验并补漏

```bash
python3 $S/build_xlsx.py <工作目录>/scenes.json <工作目录>/assets.json --check
```

- 错误（ID 重复、引用不存在的场次、资产没有状态）必须修
- 警告「人物行中的某某没有对应资产」：补资产或补 `aliases`
- 警告「某某出场但没有分配到任何状态」：回到那一场的原文，把人物分到正确的状态里
- 警告「某某的状态 XX 引用了此场次，但剧本人物行里没有某某出场」：说明状态数据手工编辑或合并时写错了场次号，去对应人物的那个状态里把这个场次删掉，再看它本该属于哪个状态
- 反复执行，直到没有错误，警告也都处理完或确认可以忽略

这一步做的是**双向校验**：不仅要保证人物行出场的都分配了状态（正向），还要保证分配进状态的场次该人物确实出场（反向）。只做正向校验会漏掉"把场次塞错了状态/塞给了不存在的出场"这类问题——合并资产、批量改场次号时最容易出这种错，必须两个方向都跑一遍再确认没有警告。

**禁止在第 3 步有任何错误或警告的情况下跳到第 4 步生成 Excel。** `--check` 必须显示「错误 0 条，警告 0 条」才能继续；无法消除的警告要先跟用户确认是否可以忽略，不能自行默认忽略后直接生成。

### 4. 生成 Excel

```bash
python3 $S/build_xlsx.py <工作目录>/scenes.json <工作目录>/assets.json <剧本目录>/<剧名>-资产表.xlsx
```

生成之后，**不代表校验就此结束**。还要用剧本原文抽查几个有多个状态的主要人物（尤其是男女主角）：对每个状态，找到它名字/描述对应的原文依据，确认原文写的场次和状态归属一致，而不是状态名和场次号对不上（例如把"龙形显现"这种描述塞进了实际是"婚礼"的场次里）。这种错误 `--check` 的程序校验查不出来，只能靠回查原文发现。

### 5. 汇报

用几句话说明以下内容：
- 人物、场景、道具各有多少个资产、多少个状态
- 合并了哪些同名异称
- 待人工确认的条目（疑似同一道具、拿不准是否该拆状态的变化）
- `--check` 的结果（确认是 0 错误 0 警告，不要略过不提）

不要把整张表复述一遍。

**交付物**：
- `<工作目录>/assets.json` - 资产数据
- `<剧本目录>/<剧名>-资产表.xlsx` - Excel 表格

（`scenes.json` 等中间文件保留在工作目录，但不向用户提及或传递）

## 状态规则摘要

只有换了一套衣服，或者外表有很大变化，才拆出新状态。表情、动作、日夜、灯光都不算。完整规则见 `references/asset_schema.md`。
