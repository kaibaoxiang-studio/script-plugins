# 动作表演指导字段规则

来源：jimeng-storyboard-v3/references/common-performance.md + leo's/references/performance-direction.md + directing-grammar.md

## 情绪双通道 B：姿态与重心

适用于中景、全景和远景：

| 情绪 | 可拍姿态 |
|------|---------|
| 戒备 | 双肩内收、重心后移、侧身半转 |
| 防御 | 蜷肩含胸、手臂横护、护住物件 |
| 抗拒 | 肩部转开、身体后仰、避开视线 |
| 急切 | 上身前倾、跨步靠近 |
| 强撑 | 脊背绷直、下颌抬起、负手而立 |
| 崩溃 | 身体下滑、脊背塌下、扶物支撑 |

## 动作设计原则

- 一个节拍只保留一个主要叙事动作
- 并行的呼吸、视线、手部动作服务于主动作
- 动作有起点、过程、终点
- 结尾残留只在有叙事价值时写

### 可演动作优先级

用主动动词：试探、安抚、逼迫、诱导、掩饰、拒绝、拖延、夺回。

不写结果表情：不写"神秘而紧张地微笑"，写"用轻描淡写迫使对方暴露恐惧"。

### 手部安全

- 优先使用整只手与物件/身体接触：握住、按住、攥衣料、扶桌
- 手部特写只写静态或慢速确定姿态
- 禁止孤立手指的快速精细动作、复杂手势、连续掐诀或灵巧翻转

## 多人场景规则

分别写主角主行动和对手回应动作，最后写两人停留关系。不得让所有人同时抢动作。

多人动作-反应链格式：
```text
主体A的台词/动作 → 主体B即时或迟滞反应 → 下一动作
```

## 动作设计补充规则

来源：知识库/导演相关/动作导演/人物动作设计.html + 身份、状态与微动作.html + 表演相关/演出导演.html

### 三层动态公式

一个完整动作必须写出三层：

```
主体 + 主动作（速度/幅度/气质）
+ 身体联动（肩膀/上身/手臂/头部配合）
+ 辅助动态（衣袖/发丝/配饰的跟随惯性）
```

不能只写"人物走路"，要写清楚：她是缓缓地走、端庄地走、步伐放轻、整体克制。

### 动作链结构

```
起始状态 → 主动作（速度/力道）→ 辅助动作（联动部位）→ 结束状态
```

缺少结束状态容易导致视频收尾混乱。

### 身份与动作匹配

动作描述前必须隐含身份信息：职业、年龄、当前处境决定动作方式。

| 身份类型 | 动作特征 |
|---------|---------|
| 宫廷/官员 | 步伐端庄、动作幅度克制、重心稳定 |
| 受伤人物 | 动作幅度受限、重心偏移、有保护性姿态 |
| 紧张/警觉 | 步伐放轻、肩背收紧、视线在多方向移动 |

### 不对称动作原则

凡需要真实感的镜头，都需要一个导致不对称的具体动机：持物/对抗环境/重心偏移。对称动作会产生"AI生成感"。

### 多角色动作分配

多角色动作不能写在同一句话中；必须逐人写动作，并明确时间先后（谁先动/谁跟随/谁保持静止）。修改多角色中某一人时，必须明确锁定保留部分。

## 权限边界

可以补充：眨眼、吞咽、鼻息、换气、指尖收紧/松开、衣料轻响、肩背细微变化、原地重心调整。

不得补充：新的人物接触、新步数或路径、新道具操作、新人物、新剧情事件、改变角色权力关系的动作。

## 去 AI 感诊断

| 症状 | 改法 |
|------|------|
| 眉眼嘴同时夸张变化 | 只指定一个首发通道和一个后续动作 |
| 每句都点头、摊手、抿嘴 | 分配持续物理任务并写明何时中断 |
| 反应早于刺激 | 明确"听见/看见后，短暂停顿，再……" |
| 两人同频表演 | 一人行动、一人接收，再交换主动权 |

## 场记表「动作表演指导」列输出格式（与 SKILL.md 一致）

格式：`起始姿态 → 核心动作（→ 结尾残留）`，**15 字以内**，只写可拍的肢体动作。

上方三层动态公式、身份匹配表、不对称动作原则、多角色分配均为**判断依据**，不直接写入字段。结尾残留只在有叙事价值时写。

示例：
- `弯腰拄棍翻石`
- `扔棍扑向绿芽`
- `脚滑后仰翻滚`
- `拔簪递出被拒缩回`
- `跪地磕头，额头着地`
