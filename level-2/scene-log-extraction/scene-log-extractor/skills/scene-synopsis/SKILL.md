# Scene Synopsis

从剧本或节拍中提炼当前 P 段的核心叙事价值，用于场记表「剧情大纲」列。

## 输入

当前 P 段的剧本原文或分镜节拍描述。

## 输出

单一字段值，直接填入场记表「剧情大纲」列。格式：`[事件/功能] + [力量变化/结果]`，一句话，15 字以内。

## 权限边界

- 只提炼当前 P 段的叙事价值，不跨段总结
- 不写摄影、表演、情绪形容词
- 不新增剧本中不存在的剧情事实
- 不填写其他列的内容

## 输出规则

- 一句话，15 字以内
- 格式：[事件/功能] + [力量变化/结果]
- 不写摄影、表演、情绪形容词
- 回答：删掉这段观众会损失什么

## 判断力量变化

力量变化指：行动权、信息权、关系距离、主动权的转移。

| 变化类型 | 写法示例 |
|---------|---------|
| 主动权转移 | 从被动转主动 |
| 信息揭露 | 发现/得知/意识到 |
| 关系建立/破裂 | 转机/决裂 |
| 状态改变 | 开场/触发/完成 |
| 无新变化（承接拍） | 强化/延续/余韵 |
