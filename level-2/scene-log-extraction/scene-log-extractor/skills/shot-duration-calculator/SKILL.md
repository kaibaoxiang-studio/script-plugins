# Shot Duration Calculator

计算当前 P 段的估算时长，用于场记表「时长」列。

## 输入

当前 P 段的台词文字、动作描述和停顿线索；模型参数可选。

## 输出

初步建议秒数与依据；Excel 写 `约Xs`，JSON 保存秒数、依据和 `pending` 待审状态。

## 权限边界

- 只做时长估算，不修改台词或动作内容
- 不把模型上限当作剧本拍长上限；给了平台参数时可额外提示制作适配风险
- 不填写其他列的内容

## 计算公式

`4 字≈1 秒` 仅作中文对白的粗略参考，不是硬公式。

时长 = max(台词时长, 动作时长)

台词时长 = 台词字数 ÷ 4（秒）
动作时长 = 动作节拍数 × 2-3 秒（视复杂度）

## 时长边界

不设固定最低值、最高值或强制拆 P 阈值。优先看真实台词、行动和停顿；无法可靠估计时明确列出不确定性。

## 动作时长参考

| 动作类型 | 估算时长 |
|---------|---------|
| 单一表情变化 | 2-3s |
| 简单肢体动作 | 3-5s |
| 复合动作序列 | 5-8s |
| 激烈动作/坠落 | 6-10s |
| 空镜/环境建立 | 4-6s |

## 参考

规则来源：`references/knowledge.md`（时长公式、动作估值表、模型时长限制、拆 P 判定条件）

## 示例

| 输入 | 计算过程 | 输出 |
|------|---------|------|
| 台词"野菜！有救了！"（5字），简单动作 | max(5÷4≈2s, 3s)=3s → 补足最低4s | 4s |
| OS 20字 + 坠落动作 | max(20÷4=5s, 7s)=7s | 7s |
| 纯空镜，无台词 | 动作时长 5s | 5s |
| 对话 30 字 + 简单动作 | max(30÷4=8s, 4s)=8s | 8s |
