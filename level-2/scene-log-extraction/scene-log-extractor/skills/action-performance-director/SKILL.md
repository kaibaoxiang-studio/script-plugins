# Action Performance Director

从剧本或节拍中提取主体角色的核心动作，用于场记表「动作表演指导」列。

## 输入

当前 P 段的剧本原文或分镜节拍描述，以及主体角色信息。

## 输出

单一字段值，直接填入场记表「动作表演指导」列。格式：`起始姿态 → 核心动作（→ 结尾残留）`，15 字以内。

## 输出规则

- 只写可拍的肢体动作：起始姿态 → 核心动作（→ 结尾残留）
- 不写心理活动、情绪形容词
- 精简，15 字以内
- 动词优先，状态为辅

## 动作设计原则

- 一个节拍只保留一个主要叙事动作
- 并行的呼吸、视线、手部动作服务于主动作
- 动作有起点、过程、终点
- 结尾残留只在有叙事价值时写

## 权限边界

可以补充：眨眼、吞咽、鼻息、换气、指尖收紧/松开、衣料轻响、肩背细微变化、原地重心调整。

不得补充：新的人物接触、新步数或路径、新道具操作、新人物、新剧情事件、改变角色权力关系的动作。

## 多人场景

分别写主角主行动和对手回应动作，最后写两人停留关系。不得让所有人同时抢动作。
