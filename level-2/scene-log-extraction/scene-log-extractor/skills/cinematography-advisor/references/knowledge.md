# 摄影字段规则（平台中立，一拍一方案）

沿用原能力的景别、机位与镜头运动判断法。本能力下每个 P 只对应一个叙事拍，因此**一拍给一个摄影方案**，不把镜头数当作分拍依据，也不跨拍做剪辑覆盖判断。

## 景别体系

景别分三类层级：

| 层级 | 包含景别 |
|------|---------|
| 中远景/全景类 | 远景、全景、大全景 |
| 中景/中近景类 | 中景、中近景、过肩 |
| 近景/特写类 | 近景、特写、大特写、怼脸 |

一拍只选一类层级作为主景别；若本拍确有主次两个信息落点，可在方案中写出第二个落点，并在 rationale 说明它对应本拍哪一个正文单元。不要为了"景别丰富"在一拍里堆叠三类层级。

## 景别与表演通道对应

按景别选择可拍内容，超出景别承载能力的细节一律不写：

- 怼脸/大特写：只写脸、眼神、下半脸和呼吸
- 近景/特写：以微表情为主，补手和肩
- 中景：先写姿态和重心，再补可见微表情
- 全景/远景：写整体姿态、步态和轮廓，不写看不清的细微表情

## 文戏镜头取向

文戏默认静多动少：固定镜头、慢推、慢拉、慢摇、慢跟和过肩反打。

- 对白和表演镜优先固定机位
- 转场、建立或揭示镜允许缓慢位移
- 固定机位通过角度、构图、焦点、景别和主体数量变化避免扁平
- 用焦点转移替代不必要的推拉
- 决定性情绪才建议怼脸特写，不让每拍都以怼脸收尾

## 景别软路径（按叙事功能选策略）

| 叙事功能 | 可选镜头策略 |
|---------|------------|
| 建立关系 | 双人中景或过肩关系 → 接收方反应 → 关系落点 |
| 权力变化 | 受压方视角/构图 → 权力方动作或台词 → 新强弱关系 |
| 信息揭示 | 道具或视线落点 → 说话方 → 接收方反应 |
| 人物移动 | 运动起点 → 跟随或遮挡转接 → 新位置关系 |
| 主观体验 | 主观视角或局部感知 → 生理反应 → 客观关系回落 |
| 冲突爆点 | 攻防关系 → 命中或反转 → 结果与余波 |

一拍内的方案只取其中真正落地的环节；完整路径写进 rationale，说明本拍取的是路径的哪一段。

## 运镜要求

每次运镜必须写清：

1. 叙事触发（为什么动）
2. 路径或速度变化
3. 停止构图（落在哪里）

没有明确动机时保持锁定或有限摇移，不用无目的推进、环绕和手持制造"电影感"。

## 镜头方位精度

涉及双人关系、过肩、床边、门边、遮挡、前后景、视线反打或人物移动时，首次建立机位以及每次换机位都要交代：

1. **摄影机位置**：相对场景固定物或人物位于哪一侧、哪一端
2. **摄影机高度与俯仰**：高度参照物及平视/俯拍/仰拍
3. **拍摄方向**："从哪里朝哪里拍"或"沿固定物A至固定物B方向拍"
4. **前景归属**：写清谁的哪一侧身体或哪个物件进入前景，以及虚实关系
5. **画面落位**：关键主体的画面左/中/右

以下词语不能裸用（必须在同句补全参照信息）：`肩侧`、`肩后`、`过肩`、`床侧`、`床边`、`侧面`、`一旁`、`近旁`、`画面边缘`、`靠近`

场记表列只放精炼方案；上述方位依据写进 JSON 的 rationale，不塞进单列字符串。

## 推镜头与变焦必须区分

| 类型 | 背景变化 | 视差 | 效果 |
|------|---------|------|------|
| 推镜头（Dolly In） | 有视差位移 | 有 | 空间纵深 |
| 变焦（Zoom） | 只有大小变化 | 无 | 扁平、像缩放图片 |

需要强调纵深时写"推镜头"或"Dolly In"，不要用"变焦"代替。

## 运动描述格式

感性形容词（"画面震撼"）对视频模型无效，也不属于可核对事实。改用结构化描述：

**主体 / 动作 / 镜头**。剔除氛围词、风格词和"电影感"等观后感式描述。

一个完整运动镜头包含四层信息：

```text
主体动作：移动方向 + 速度 + 起终点
跟随动态：衣物、发丝、配饰的惯性
光线变化：移动中光线如何随空间改变
声音连接：环境音从远到近、从静到动
```

## 双人对手戏调度

两人对话用调度动作（遮挡、观察、靠近、挡路）建立空间关系，不写"两人面对面站立"：

```text
遮挡建立位置 → 观察/探查 → 移动/靠近 → 关系结果
```

调度动作必须有正文依据；原文只写"两人交谈"时不新增走位，改用机位与过肩关系呈现。

## 设备与焦段倾向

| 场景类型 | 建议设备 |
|---------|---------|
| 动态追逐、情绪激烈 | 手持 |
| 静态对话、稳定叙事 | 肩扛 / 三脚架 |
| 跟随人物移动 | 斯坦尼康 |
| 航拍、大全景 | 无人机 |

焦段只作倾向，不伪装成精确参数或器材承诺：16–24mm 环境交代与空间感，35mm 自然视角，50mm 人物关系，85mm 人物特写，135mm+ 长焦压缩。

## 输出格式

场记表「摄影」列格式：`设备，焦段，机位，镜头运动`

- 四项逗号分隔关键词，保持精简
- 不为凑字数而省略必要的机位信息
- 焦段仅写倾向，如 `50mm` 或 `中长焦`
- 条件不足（正文看不出空间关系、人物位置或动作落点）时输出 `—`，并在 JSON 的 uncertainties 写明缺什么

示例：
- `肩扛，16mm，水平略俯，静镜`
- `手持，50mm，眼平双人，静镜`
- `手持，85mm，POV→过肩`
- `三脚架，35mm，略俯，缓推`

## 权限边界

- 依据叙事动机选择，不为炫技堆砌运镜
- 不新增剧本中未发生的动作、人物或道具
- 不写"电影感""大片感"一类不可拍摄的评价词
- 本文件规则已内置，独立可用，无需安装其他 skill
