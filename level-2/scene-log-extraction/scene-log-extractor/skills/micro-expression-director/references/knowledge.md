# 微表情情绪指导字段规则

来源：jimeng-storyboard-v3/references/common-performance.md + leo's/references/performance-direction.md

## 情绪双通道 A：微表情与呼吸

适用于近景、特写、大特写：

| 情绪 | 可拍动作 |
|------|---------|
| 震动、错愕 | 呼吸一顿、唇微张、瞳孔微缩 |
| 隐忍、倔强 | 下颌绷紧、下唇抿紧、喉头滚动 |
| 卸防、动容 | 唇线松开、眼眶发热、呼吸放缓 |
| 无声哭 | 下唇咬紧、喉头滚动、肩膀细颤 |
| 冷酷、压迫 | 目光一沉、下颌收紧、唇角冷压 |

**原则**：把抽象情绪翻译成模型能执行的动作。不写"震惊、隐忍、苍白、动容"等词。

## 刺激—调整—动作时间链

```text
看见/听见刺激
→ 眼神或呼吸先产生最小调整
→ 身体任务被中断或改变
→ 台词/动作作为策略出现
→ 句后留下余波与新状态
```

**关键**：每个节拍从通道中选择 2—4 个，不能全部堆满。避免所有部位同时启动。

## 微表情可选通道

| 通道 | 可执行变量 |
|------|----------|
| 目光 | 落点、停留、移开原因、眨眼频率、是否先看物再看人 |
| 呼吸 | 深浅、是否屏息、吐气点、台词前后气口 |
| 面部 | 下颌、嘴角、眉间、眼睑的单一细微变化 |
| 重心 | 前倾/后撤、肩背开合、是否保留逃离方向 |

## Render-safe 绝对禁令

- **瞳孔和眼球发光绝对禁止**：金光、血光、红光、蓝光、冷光、光点、光束和能量不能进入瞳孔、眼白或眼球
- 不写"眼中精光、寒光、瞳孔灼光或眼神发亮"；改写"目光一利、眼神一沉、瞳孔缩放"
- 不写整脸"涨得通红"；改写"脸颊紧绷、耳根局部泛红"
- 不写"赤红、猩红或实色红眼"；改写"眼白泛红、布满血丝"
- 允许：自然泪光、眼白血丝、眼里映着某人

## 微表情设计补充规则

来源：知识库/导演相关/表演相关/情绪导演.html + 动作导演/身份、状态与微动作.html

### 情绪词转可拍动作

禁止直接使用大情绪词（大笑/愤怒/悲伤）；改用 faint/subtle/barely visible/suppressed 修饰，防止表情锁死在100%强度。

| 禁用写法 | 替换写法 |
|---------|---------|
| 她很害羞 | 低头回避眼神、下意识咬住下唇、手指轻轻收紧 |
| 他很犹豫 | 食指指尖在下嘴唇边缘不自觉来回摩挲 |
| 表情难过 | 眉头微蹙、嘴唇轻轻抿住、眼眶微湿但没有落泪 |

### 神态三阶段流动

写神态时必须写成流动过程，不写静态结论：

```
起始神态 → 过渡神态（触发点）→ 高潮神态（余波）
```

### 微表情时间链

```
看见/听见刺激
→ 眼神或呼吸先产生最小调整（首发通道）
→ 身体任务被中断或改变
→ 台词/动作作为策略出现
→ 句后留下余波与新状态
```

关键：每个节拍从通道中选择 2—4 个，不能全部堆满；非关键通道保持稳定，使观众能看见那一次变化。

### 微动作词库（优先于情绪结论词）

嘴角轻微上扬 / 眉毛微蹙又放松 / 睫毛轻颤 / 喉咙微动 / 眼睑轻轻眨动 / 鼻翼细微收紧 / 下颌肌肉一紧 / 指尖收拢

### 消除摆拍感

- 引入"环境对抗"因素：微风→按住衣领，台阶→重心偏移，这类外部阻力会产生自然不对称感
- 描述"过渡瞬间"而非"已完成状态"：转身刚开始时/步伐迈出一半时，惯性自然发生
- 避免"全程保持眼神交流"；允许视线在多方向间移动

## 权限边界

可以补充：眨眼、吞咽、鼻息、换气、指尖收紧/松开、衣料轻响、肩背细微变化、原地重心调整。

不得补充：新的人物接触、新步数或路径、新道具操作、新人物、新剧情事件、改变角色权力关系的动作。

## 场记表「微表情情绪指导」列输出格式（与 SKILL.md 一致）

格式：可见身体细节，以刺激→反应为逻辑，**10 字以内**。

上方情绪双通道 A、时间链、微动作词库、消除摆拍感均为**判断依据**，不直接写入字段，字段只输出最终可见细节。

示例：
- `眉紧锁，眼扫视，汗密布`
- `眼骤亮，鼻翕动`
- `鼻翕，眼锁定，喉结动`
- `眼犹豫转决定，手颤`
