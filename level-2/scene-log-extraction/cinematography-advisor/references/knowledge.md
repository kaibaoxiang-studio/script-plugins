# 摄影字段规则（平台中立）

沿用原能力的景别、机位与镜头运动判断法，但每个 P 现在只对应一拍，因此不要求单拍覆盖多类景别，也不把镜头数当作分拍依据。

- 先确认本拍的主体、动作或信息落点，再选择能拍清它的设备、焦段倾向、机位和运动。
- 人物关系可用双人中景、过肩或接收方反应；信息揭示可让镜头跟随原文已有道具或视线。不能新增原文没有的动作或道具。
- 文戏优先稳定机位；有明确运动动机时才建议推、拉、跟或摇，并说明落点。焦段只是初步建议，不是实际器材承诺。
- 人物或摄影机换位时复核轴线、前景归属和视线关系；表格列只写精炼方案，依据留在 JSON 的 rationale。
- 模型、画幅未提供时采用平台中立判断；提供后作为限制条件，不倒推剧本事实。

输出示例：三脚架，50mm，眼平双人，静镜。条件不足时输出 — 并报告待审原因。
