# 剧情大纲提炼规则

来源：jimeng-storyboard-v3/references/dramatic-staging.md + leo's/references/directing-grammar.md

## 导演命题思维

开始提炼前，先回答：
- 观众在本段新知道什么？
- 人物关系或力量对比发生什么变化？
- 删掉这段观众会损失什么？

将这些答案压成一句话。

## 力量变化类型

力量变化指：行动权、信息权、关系距离、主动权的转移。

| 变化类型 | 写法示例 |
|---------|---------|
| 主动权转移 | 从被动转主动 |
| 信息揭露 | 发现/得知/意识到 |
| 关系建立/破裂 | 转机/决裂 |
| 状态改变 | 开场/触发/完成 |
| 无新变化（承接拍） | 强化/延续/余韵 |

## 戏剧演出卡的"主线"字段参考

- **变化拍**：`状态A → 状态B`，只保留一条主要情绪、关系、认知或行动变化
- **承接拍**：`状态保持（余韵）`、`状态保持（悬置）`、`状态保持（对峙）`等

## 输出格式约束

格式：`[事件/功能] + [力量变化/结果]`

- 一句话，15 字以内
- 不写摄影、表演、情绪形容词
- 不新增剧本中不存在的剧情事实
- 只提炼当前 P 段的叙事价值，不跨段总结

## 示例

| 输入 | 输出 |
|------|------|
| 荒山绝境开场，苏老太挣扎求生 | 荒年求生开场 |
| 苏老太发现绿芽，从绝望转主动 | 发现希望转主动 |
| 苏老太坠崖触发穿越 | 坠崖触发穿越 |
| 穿越至现代，环境完全陌生 | 穿越至现代 |
| 递簪换食失败，但找到典当方向 | 首次换食失败 |
| 顾云等待林深到来，主动权在外 | 顾云等待；信息权在外 |
| 林深表态，关系由僵持转为主动 | 林深表态转主动 |

## 权限边界

- 只提炼当前 P 段的叙事价值，不跨段总结
- 不写摄影、表演、情绪形容词
- 不新增剧本中不存在的剧情事实
- 不填写其他列的内容
