# 灯光/色卡字段规则（平台中立，一拍一方案）

沿用原能力的光源锚点、光影结果判断法和连续性规则。本能力下每个 P 只对应一个叙事拍，因此**一拍给一个灯光方案**；光源延续性以本拍正文和相邻上下文为依据，不跨拍做无依据的改变。

## 最小光源锚点（四项必填）

每拍必须建立可执行的最小光源锚点，四项缺一不可：

1. **真实来源**：窗户自然光、门外天光、顶灯、壁灯、灯笼、烛火、火焰或月光等场景中实际存在的光源；不得只写"电影光""氛围光""高级光影"或未说明来源的"主光"
2. **方向**：绑定门窗、灯具、床头/床尾、人物受光侧等可追踪关系；不得只写抽象的"侧光"
3. **质地**：至少说明冷/暖/中性以及柔光/硬光
4. **效果**：默认写"自然明暗塑形，无额外风格化灯光效果"；只有用户明确指定灯光偏好（体积光/色彩光/动态光/轮廓分离）时，才按所选效果给建议，并在 rationale 标注这是用户制作约束

正文没有写明光源时，不得把猜测写成场景事实。可以给待审建议，但必须在 uncertainties 说明假设依据。

## 光影结果（判断依据，不直接写入列）

填写前在内部核对以下六项；场记表列只写精炼结果，依据写进 JSON 的 rationale：

```text
主体光区｜明暗层级｜暗部与高光｜分离方式｜材质响应｜移动受光
```

| 字段 | 填写规则 |
|------|---------|
| 主体光区 | 逐一说明关键主体处于完整光区/明暗交界/可读逆光/可读暗部/剪影中的哪种状态 |
| 明暗层级 | 说明第一注意力对象，以及主体相对背景更亮/持平/更暗的关系 |
| 暗部与高光 | 阴影侧是否保留表情动作，需要保护的高光不过曝 |
| 分离方式 | 从明暗、冷暖、景深、遮挡中选最少有效方式；新增轮廓光仅在用户指定效果时使用 |
| 材质响应 | 当前镜头真正重要的一至三种材质的纹理/灰阶/反射是否受控 |
| 移动受光 | 跨光区时写起点/终点/过渡；无跨光区写"不适用，当前光影结果保持稳定" |

## 打光类型

| 打光类型 | 核心特征 | 适用场景 |
|---------|---------|---------|
| 侧逆光 | 光源在人物侧后方，边缘出现轮廓亮边 | 人物出场、回头、等待、相遇、擦肩 |
| 轮廓光 | 强光从侧后方或背后切出人物边缘 | 夜景/暗背景人物分离、战损站位 |
| 暖色轮廓光 | 金色/橙色边缘光 | 温暖、浪漫、命运感场景 |
| 冷色轮廓光 | 蓝色/银色边缘光 | 冷静、神秘、悬疑场景 |
| 侧光（45度） | 一半脸亮一半脸暗 | 独白、秘密揭晓、内心挣扎 |
| 硬光 | 光影边缘清晰锐利 | 商业广告、产品展示，不适合情感近景 |

使用约束：

- 主光与补光分层写：主光负责氛围和明暗结构，补光负责保留面部细节，不能混写为"均匀照亮"
- 大光比暗部不写"死黑"，需补"保留皮肤纹理、五官结构和材质细节"
- 色温显式写出：暖色侧光对应古风内室/情感戏；冷色侧光对应悬疑/反转/揭秘场景
- 体积光/神明光属于明确效果，只在用户指定时使用，并同时声明"空气中有轻微烟雾/雾气"作为光束可见的物理条件
- 眼神光不默认强加；正文有明确近景情绪需求时，可在 rationale 说明而不写进列

## 连续性规则

- 最小光源锚点在本拍方案中一次性确立
- 只在换光区、遮挡光源、开关灯、开门、闪电或其他可见光源事件发生时改变方案
- 没有光源事件时，来源、方向、质地和效果延续上一拍，列中写 `同上`
- 人物或摄影机移动只改变受光结果，不得无因改变光源身份
- 延续判断需能在正文或相邻上下文中找到依据；找不到时按本拍可见条件重新给方案，并在 uncertainties 说明

## Render-safe 绝对禁令

- 不写整脸"涨得通红"；改写脸颊紧绷、耳根或脖颈局部泛红
- 不写赤红、猩红或实色红眼；改写眼白泛红、布满血丝
- **瞳孔和眼球发光绝对禁止，无例外**：金光、血光、红光、蓝光、冷光、光点、光束和能量不能进入瞳孔、眼白或眼球
- 允许：自然泪光、眼白血丝、眼里映着某人，以及酒渍、血泊等真实红色物体

## 色调关键词

| 场景类型 | 色调 |
|---------|------|
| 荒年、贫苦、古代压迫 | 焦黄、土灰、暗褐 |
| 现代都市、陌生感 | 冷白、高饱和 |
| 亲情、温暖时刻 | 暖橙、暖黄 |
| 危机、恐惧 | 冷蓝、低饱和 |
| 夜晚、秘密 | 深蓝、烛光暖 |

色调必须由本拍场景、时段和光源条件支撑；不得仅凭情绪给色。

## 光源方向速查

| 方向 | 适用 |
|------|------|
| 顶光 | 烈日、压迫、荒凉 |
| 侧光 | 人物塑形、戏剧张力 |
| 逆光 | 剪影、神秘、情绪 |
| 侧逆光 | 勾边、立体感 |
| 散射光 | 阴天、柔和、室内 |

## 输出格式

场记表「灯光/色卡」列格式：`光源方向，色调关键词`，精简为一到两个关键词组。

- 同场景延续且无变化时输出 `同上`
- 无法从正文判断光源时输出 `—`，并在 uncertainties 写明缺什么
- 不写"电影感""高级感"一类不可拍摄的评价词

示例：
- `侧逆光，冷蓝`
- `顶光，焦黄偏白`
- `散射光，暖黄柔和`
- `侧光，暗褐低饱和`
- `同上`

## 权限边界

- 只写场景中真实存在或被明确指定的光源
- 不虚构灯具、人工光效或光源事件
- 不填写其他列的内容
- 本文件规则已内置，独立可用，无需安装其他 skill
