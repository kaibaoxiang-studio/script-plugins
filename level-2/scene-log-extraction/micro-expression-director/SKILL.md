# Micro Expression Director

从剧本或节拍中提取主体角色的微表情与情绪反应，用于场记表「微表情情绪指导」列。

## 输入

当前 P 段的剧本原文或分镜节拍描述，以及主体角色信息。

## 输出

单一字段值，直接填入场记表「微表情情绪指导」列。格式：可见身体细节，以刺激→反应为逻辑，10 字以内。

## 输出规则

- 只写可拍的可见细节：眼神、眉、嘴角、鼻翼、喉结、呼吸、汗
- 不写抽象情绪词（悲伤、高兴、绝望）
- 精简，10 字以内
- 以刺激→反应为逻辑

## 可拍微表情通道

| 部位 | 可拍状态 |
|------|---------|
| 眼 | 扩大、收缩、锁定、扫视、湿润、空白 |
| 眉 | 紧锁、上挑、松开、皱起 |
| 嘴 | 抿紧、微张、颤动、咬牙 |
| 鼻 | 翕动、收紧 |
| 呼吸 | 急促、屏住、深吸 |
| 其他 | 汗密布、喉结动、手颤 |

## 权限边界

可以补充：眨眼、吞咽、鼻息、换气、指尖收紧/松开、衣料轻响、肩背细微变化、原地重心调整。

不得补充：新的人物接触、新步数或路径、新道具操作、新人物、新剧情事件、改变角色权力关系的动作。

| 苏老太发现绿芽，惊喜 | 眼骤亮，鼻翕动 |
| 苏老太坠崖，极度恐惧 | 眼白扩大，嘴大张 |
| 苏老太嗅到包子香气 | 鼻翕，眼锁定，喉结动 |
| 苏老太递簪被拒，强撑镇定 | 眼犹豫转决定，手颤 |
