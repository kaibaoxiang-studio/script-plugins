# Dialogue Formatter

从剧本中提取并格式化当前 P 段台词，用于场记表「台词」列。

## 输入

当前 P 段的剧本原文，包含对白、OS 或 VO 标注。

## 输出

单一字段值，直接填入场记表「台词」列。格式：保留原文，多句换行，OS/VO 标注在说话人后，无台词输出 `—`。JSON 还逐块保存原文和来源。

## 权限边界

- 严格保留原文，不改写不删减，不移位任何词
- 长台词也完整保留，不加省略号、不截断；若需另拍，由分拍阶段决定
- 不填写其他列的内容
- 不增加剧本中不存在的台词

## 输出规则

- 严格保留原文，不改写不删减，不移位任何词
- 多句按原顺序换行，并保留说话人
- OS/VO 在说话人后用括号标注
- 无台词填 —
- 双语台词保持原有语言顺序和内容

## 台词类型

| 类型 | 格式 |
|------|------|
| 普通对白 | 甲：原文 |
| 内心独白 OS | 甲（OS）：原文 |
| 画外音 VO | 甲（VO）：原文 |
| 多人对白 | 逐人换行，保持原顺序 |

## 示例

| 输入 | 输出 |
|------|------|
| 苏老太惊喜喊：野菜！有救了！ | 苏老太：野菜！有救了！ |
| 苏老太OS：完了……我死了，大强他们可怎么办！ | 苏老太（OS）：完了……我死了，大强他们可怎么办！ |
| 苏老太：我能用这个换您一个包子吗？老板：这是包子铺不是典当铺 | 苏老太：我能用这个换您一个包子吗？（换行）老板：这是包子铺不是典当铺 |
| 纯动作节拍，无台词 | — |
