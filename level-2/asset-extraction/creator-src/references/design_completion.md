# 设计补全

资产数据分两层，Excel 中合并在同一单元格（基础设定、状态描述、子场景描述）分段展示：先「【原文】」剧本事实，再「【设计】」逐行列出设计字段，末行「【依据】」。原文层只有「…未说明」之类的缺口记录时，表格不显示【原文】段，只显示【设计】段。

| 层 | 字段 | 作用 | 能否写「未说明」 |
| --- | --- | --- | --- |
| 原文事实 | `description`、`evidence`、`visual`、appearances | 判断资产、状态拆分、出现场次 | 可以，如实记录原文缺口 |
| 设计补全 | `design`、`design_basis` | 美术、服化道、场景搭建直接使用 | 不可以，必须给出具体设计 |

设计补全只用于展示和制作，**不能**据此新增资产、拆分状态、分配场次或判断出镜。状态边界仍只看原文。设计不得与原文矛盾：原文写了「灰黑色训练制服」，设计只能细化款式和材质，不能改成蓝色。

## 必填字段

`design` 是对象，以下键全部必填；`design_basis` 是字符串。

| 位置 | design 键（Excel 显示名） |
| --- | --- |
| 人物本身（主角、主要配角、配角） | `age` 年龄段、`build` 身高体型、`face` 脸型五官、`hair` 发型发色、`skin` 肤色、`temperament` 气质神态、`signature` 标志性特征、`identity` 身份与时代背景 |
| 人物每个状态（主角、主要配角、配角） | `costume` 服装款式、`color_material` 颜色材质、`accessories` 配饰、`hair_makeup` 妆发、`injury_stains` 伤势污损、`difference` 与其他状态差异 |
| 群演本身（`role` 为「群演」） | `age` 年龄段、`identity` 身份与时代背景、`overall` 整体外形特征（体型、发型、统一妆容等群组共性） |
| 群演每个状态 | `costume` 服装款式、`color_material` 颜色材质 |
| 场景每个子场景（无子场景时写在场景本身） | `layout` 空间结构与尺度、`furnishings` 主要陈设、`material_color` 材质色调、`lighting` 光源光线、`style` 时代风格、`atmosphere` 氛围 |
| 场景第二个及以后的状态（如战后废墟、婚礼布置） | `appearance` 本状态布置或破坏、`difference` 与常态差异；显示在场景表备注的对应状态下。首个状态即子场景设计本身，不填 |
| 道具本身 | `shape_size` 外形尺寸、`material_color` 材质颜色、`structure` 结构细节、`markings` 标记纹饰、`usage` 使用方式 |
| 道具每个状态 | `appearance` 本状态外观、`damage` 破损污损、`difference` 与其他状态差异 |

人物「外观未说明」状态（`basis: unspecified`）同样要填设计：原文层保持「未说明」，设计层按身份、场合和前后状态给出合理造型，并在 `design_basis` 说明这是推断。

群演按群组制作，填精简版即可。某个群演需要单独设计（例如有特写、会反复出现的头目）时，按角色类型规则改为配角，就会要求填全套字段。不能为了少填字段把有台词的角色归为群演。

## 怎么写

- 每项写到美术能直接出图、服化道能直接备料的程度：款式、颜色、材质、尺寸、位置、程度。例如「深灰色立领拉链训练服，哑光尼龙面料，左胸白色学员编号 0417，袖口卷到小臂」，而不是「训练服」。
- 「没有」也要写成具体结论：「不佩戴配饰，仅左腕一块黑色军用手环」「无伤，制服干净平整」。单写「无」「略」「同上」「见原文」会被拦截。
- 禁止在设计字段里出现：未说明、未描写、未明示、未提及、不详、待设计、待确认、待补充、待定、暂无、无法确定、剧本未、原文未。信息缺口写进 `design_basis` 的推断理由，设计值本身给出结论。
- 同一人物各状态共享基础设定，状态的设计段只写本版本的服装、妆发、伤污和差异，`difference` 写清与哪个状态比、改了什么。只有一个状态时写「全剧单一造型」并说明为何不变。
- 同一世界观的人物、场景、道具保持一致的时代、科技水平和色彩体系。

## 依据优先级

`design_basis` 按以下顺序取依据，并写明每类信息的来源：

1. 用户提供的美术设定、人设图或世界观文件（写「设定文件：<文件名>」）。
2. 剧本首场前的设定区（`parse_reviews` 中的设定参考、人物造型、人物小传、大纲），写段落号。
3. 剧本正文对该资产或同场的描写，写场次和行号。
4. 按人物身份、年龄、职业、剧本时代与类型推断，写清推断理由。

示例：`发色、疤痕来自设定区第 12 段「左颊一道斜疤」；身高体型按 28 岁一线机甲驾驶员推断；服装材质按 3050 年军用驾驶服推断。`
