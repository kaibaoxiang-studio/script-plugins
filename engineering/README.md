# 额外工程：Harness Creator

Harness Creator 是通用业务能力插件建设与维护工程，展示名为 **Harness Creator**，组件版本 **0.1.0**。它提供需求对齐、能力架构、来源整合、知识维护、Skill 编写、构建和验证能力。

它不属于剧本的一级或二级业务节点。三个业务插件可独立使用；团队需要创建新能力或维护构建时再选装 Creator。
