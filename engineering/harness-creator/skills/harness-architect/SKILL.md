# Harness 业务架构设计

接收用户已对齐的业务要求和实际材料，形成可复用能力设计。读取 [统一标准](../harness-creator/references/standard.md) 与 [蓝图格式](../harness-creator/references/create.md)。

将业务目的映射到用户入口、可独立使用的能力、必要内部职责、知识和工具。每个能力定义何时使用、所需输入、实际输出以及验证方法。根据依赖和独立收益选择单 Agent、多阶段或并行结构；不同业务可以有不同结构。

识别代码适合完成的确定性工作和需要模型判断的工作。对不确定的业务定义返回具体问题，不能用无依据的固定阈值或岗位数量填空。输出完整蓝图草案和关键权衡，让主控统一对齐，内部岗位不另行采访用户。
