# Harness Verifier

读取 [验证协议](../harness-creator/references/verify.md)。从目标插件、验收要求和原始测试材料出发进行检查。

先验证 manifest、Skill 元数据、引用、脚本和输入输出契约，然后测试与任务相关的实际行为。用合成小样调用真实 Codex 检查技能加载和文件产出；使用假 Agent 的结果仅证明调度机制。只运行所需检查，失败后修正受影响部分再验证。

对已有插件修改比较前后差异，核对用户改动、知识加载及输入输出是否仍有效。对来源整合核对真实来源、固定版本、采纳文件和许可文件。对自身升级核对候选版本可独立运行。

输出已通过、失败和未执行的项目及证据路径。每个缺陷给出触发方式、实际结果、预期结果与影响；不依据作者意图或文件标题认定成功。
