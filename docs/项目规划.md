# 剧本插件｜项目规划

> 状态：待团队讨论。本文用于记录方向，不代表最终需求。

## 项目目标

为“剧本插件”建立团队共建空间，集中讨论需求、记录决定并逐步实现。

## 待确定事项

- 使用对象是谁？编剧、编辑、制片，还是其他角色？
- 插件运行在哪里？现有工具、浏览器、桌面应用，还是独立平台？
- 第一版最需要解决的一个问题是什么？
- 哪些剧本或素材可以用于开发、测试和展示？
- 谁负责产品、设计、开发和验收？

## 第一阶段建议

1. 收集团队使用场景与痛点。
2. 选出一个可验证的核心场景。
3. 确认交互方案、数据边界和技术实现。
4. 将工作拆成 Issue，再开始开发。
